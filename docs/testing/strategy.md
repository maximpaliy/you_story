## Principles

- Test behavior and contracts rather than implementation trivia.
- Prefer fast deterministic tests at lower levels.
- Use integration tests where boundaries can fail independently.
- Use end-to-end tests for a small number of critical user journeys.
- Include security, authorization, data integrity, and failure-path checks where relevant.
